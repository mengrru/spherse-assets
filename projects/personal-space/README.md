# 生活广场 · 使用手册

一个把日常生活收进来的本地工作台：**一个仪表盘 + 五个小应用 + 一个小助手**。
数据都存在这个项目里。你可以打开任意小应用直接使用。

---

## 一分钟上手

1. 打开项目，落在**仪表盘**上：今天要紧的事、待看的、正在看的、今日推荐，一眼扫完。
2. 从**侧边面板**点任意应用就能打开。条目右侧的 **⧉** 用浮窗打开，可以和主界面并排看；面板上的小徽章表示「有事等着」（进行中 / 待分流 / 在追的条数）。
3. 想动嘴不动手时，打开**小助手**，直接说要做什么（见下文「和小助手一起用」）。

---

## 五个应用

| 应用 | 一句话 | 怎么用 |
| --- | --- | --- |
| ⚡ **事务簿**<br>`todo/事务簿.html` | 要办的事 | 输入框写一件事，回车写入。支持内联语法：`换灯泡 #家务 p1`（`#` 跟类别，`p1/p2/p3` 跟优先级）；点卡片上的圆环推进状态（未开始 → 进行中 → 完成），列头可切换按状态 / 优先级 / 类别分组 |
| 🗂 **收件箱分流器**<br>`inbox/收件箱分流器.html` | 先丢进来再决定 | 把任何东西丢进输入框（粘贴多行会自动拆成多条）。之后逐条判定去向：待办 / 笔记 / 参考 / 丢掉；点「交给小助手分流」可以让小助手先给建议，你在页面上一键同意或改判（改判会记成你的偏好） |
| 🎬 **待看与在追**<br>`backlog/待看与在追.html` | 电影 / 剧集 / 游戏 / 书的清单 | 想看的进清单；在追的带进度条，配「+10% / 看完了 / 弃了」快捷动作（电影不显示进度条）；看完或弃坑后可以打 1–5 星，评分会用来算口味 |
| 📦 **收纳地图**<br>`storage/收纳地图.html` | 东西放哪儿了 | 打开即聚焦搜索框，输物品名 / 标签 / 房间都能找到，结果直接告诉你「房间 › 位置」。位置卡里那行「＋ 往里放东西」可以连续录入，也支持 `毛衣 x3` 和整段粘贴；物品能就地编辑、跨位置搬运 |
| 💰 **日常账本**<br>`ledger/账本.html` | 记一笔 | 一行搞定：`38.5 午饭 #餐饮`。`+5000 工资` 记收入，`@微信` 记支付方式，也支持补记日期。报头是本月支出和分类占比，流水按天分组，点行可就地改 |

仪表盘上的每一行都可以点，直接跳到对应的应用。

## 和小助手一起用

**小助手**是这个项目里的 AI，能读写上面所有数据。打开方式：侧边面板 →「会话」→「小助手」。
（首次点击会新建一个会话并记住它，之后点开的都是同一个；条目右侧的 **⌫** 可以清除这个「记住的会话」。）

它听得懂日常话，例如：

- 记：`把「换灯泡」加进事务簿，P1，类别家务`
- 记：`今天午饭 38.5，记在餐饮` / `收件箱里那条链接存成参考`
- 问：`我这周花了多少？` / `收纳地图里 3 号柜还有空位吗？`
- 挑：`从待看里挑一部今晚能看完的`
- 改/删：`事务簿里那件换灯泡的标记成完成` / `把待看清单里重复的那两条合并`

写完它会直接改对应的数据文件，页面订阅了文件变化，会自动刷新，不用手动操作。

## 让它给你加一个自己的小应用

这五个应用只是起手 —— **缺什么，直接让小助手给你做一个就行。** 现在这五个应用和仪表盘，最初也都是这样一句一句话长出来的。

**怎么开口**：说清「记什么」和「拿来干嘛」，越像跟人说话越好：

- `我想要一个管咖啡豆的应用：豆子名、烘焙度、买的日子、喝完没有`
- `做个喝水打卡，点一下加 200ml，看今天的总量`
- `帮我记每月账单的到期日，快到期的时候告诉我`

**它会做的事**：想清要存哪些字段 → 建一份自己的数据文件（`xxx.data.json`）→ 写页面 → 把入口加进侧边面板（要的话也放上仪表盘）→ 再告诉你怎么用。

**想一次做对，这几句可以先说：**

- 要记下来的东西（比如「豆子名 / 烘焙度 / 日期 / 喝完没」）
- 最常用的动作（一般是「加一条」「标记完成」，以及要不要能搜）
- 想在哪看到它（侧边面板里加一项、要不要上仪表盘）
- 要不要自动（比如每天早上提醒一次）

**不合适就直接说**：「分类太细了，去掉」「颜色跟其它页面统一一下」「这块挪到仪表盘上」。改到顺手为止 —— 它改的是页面和数据，你的记录不会丢。

**小建议**：先做一个很小、当天就能用起来的版本（一两个字段 + 一个动作），用顺手了再往上加。现有的应用也可以让它改（加个字段、换个分组方式都行）。

## 清空当前数据

**小助手可以读写所有数据，所以清空最省事的办法就是让它来做。**

1. 打开侧边面板，点「会话」分组里的 **🤖 小助手**。
2. 直接说清楚要清什么，例如：
   - `清空事务簿`
   - `把待看清单清空，在追的也一起删掉`
   - `清空所有应用的数据`（五个应用的记录全删，只保留文件结构）
   - `只删 8 月的账本记录`
3. 小助手会改数据文件，页面会自动刷新 —— 不需要你手动编辑任何文件。

几点提醒：

- **范围说得越具体越好。** 只说「清空」而不说清哪个应用时，小助手可能会反问你要清的范围。
- **清不掉的数据可以追问：** 比如 `还剩几条？`、`连示例数据一起删掉`。
- **清空不可撤销。** 动手前可以先问一句 `先别动，告诉我各应用现在有多少条记录`，看清了再清。

## 数据放在哪

所有数据都是项目里的普通 JSON 文件，改完页面自动跟着变：

| 文件 | 装着什么 |
| --- | --- |
| `todo/todo.data.json` | 事务簿：`todos`（标题、类别、优先级、状态、描述） |
| `inbox/inbox.data.json` | 收件箱：`items`（原文、建议去向、是否已落地） |
| `backlog/backlog.data.json` | 待看与在追：`items`（作品、状态、进度、评分）、`profile`（口味画像）、`recommendations`（每日推荐） |
| `storage/storage.data.json` | 收纳地图：`places`（位置 / 房间）、`items`（物品、数量、标签） |
| `ledger/ledger.data.json` | 日常账本：`transactions`（金额按「分」存整数，带月份与分类） |

小助手读写走的也是这些文件里的同一套入口，所以页面上做的和它做的完全一致。

## 每天自动发生的事

- **今日推荐：每天早上 08:00** 由定时任务生成一条书 / 影 / 剧 / 游推荐，读你的评分和清单来挑，写在仪表盘的「今日推荐」里。
- 推荐卡片上可以 **加入待看**（直接进「待看与在追」），也可以点 **换一个** 让它现在另挑一条（走事件触发器，稍等一下刷新即可）。
- 推荐完成时会有一条系统通知「今日推荐已就绪」。

## 遇到问题

- **页面显示「未检测到 Spherse 运行环境」**：页面要在 Spherse 里打开才有数据，直接用浏览器打开 html 文件读不到。
- **点「小助手」没反应、或提示打不开会话**：点该条目上的 **⌫** 清除掉记住的会话，再点一次会新建一个。
- **数据变了页面没跟着变**：在仪表盘右下角点「刷新」。
- **深色模式**：跟随系统设置，页面会自动切换成深色配色。
