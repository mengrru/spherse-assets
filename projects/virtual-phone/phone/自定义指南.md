# 小手机 · 自定义指南

> 这份是给**用它、想改着玩**的人的。想搞清楚内部怎么运转，看 `开发说明.md`。

小手机是一个装在本项目里的"手机"，里面住着会说话的角色。
它**绝大部分不是代码，而是文本和数据** —— 改它通常就是改几个字、加一条数据。

---

## 一、先让它跑起来

- 手机本体：`phone/engine/index.html`
- 现在有两个世界：**临江 · 2000**（现代都市日常）、**霍格沃茨 · 1993**（魔法学校）
- 换世界：**设置 → ★ 世界 ★**
- 手机里的"现在几点"由**世界时钟**决定（设置 → 手机世界时钟），基准和流速都能调（1× / 12× / 60× / 180× / 1440×）

## 二、改几个字就生效的

| 你想改 | 改哪儿 |
|---|---|
| 角色的性格、说话方式、忌讳 | `phone/worlds/<世界>/characters/*.md` |
| 这个世界长什么样、什么规矩 | `phone/worlds/<世界>/world.md` |
| 系统 Agent（短信局 / 论坛 / 电台…）的人格与版块 | `phone/worlds/<世界>/system/*.md` |
| 什么时间"谁来找你" | 那个 Agent 的**触发器**（在会话界面里配 cron） |

改完**不用重启手机** —— 这些文件是发消息时随信带给角色的（手机本身不读它们）。

## 三、加一个角色（三步）

1. **写人格卡**：写进某个**卡司文件**（如 `characters/格兰芬多同学.md`）里的一个人；也可以自己新建一个 `.md`
2. **公共数据加一条**：`phone/worlds/<世界>/data/shared.data.json` → `characters` 里加
   `{ "id", "name", "agentSlug", "personaFile", "tagline", "avatarEmoji", "avatarColor", "affection", "mood", "doing", "placeName" }`
3. **加会话**：同文件 `conversations` 里加 `{ "id", "characterId", "title" }` —— **不要填 `sessionId`**（引擎按需自己建）——
   并在 `profile.lastSeen` 里补一条已读时间戳（否则会立刻显示未读红点）

> **一个 Agent 管 3~5 个角色最舒服**：几个角色填**同一个 `agentSlug`**，各自有独立会话 → 上下文互不串。
> 角色多了就按亲疏分组（霍格沃茨就是这么分成三人组 / 同学 / 外院三组的）。

## 四、加一个世界

1. 复制 `phone/worlds/linjiang/`，改名（比如 `myworld`）

> ⚠️ **`world.data.json` 有两份，别搞混**：`phone/config.data.json` 是"**当前在跑哪个世界**"的总开关（只有一份，设置里点世界就是改它）；
> 而每个 `phone/worlds/<世界>/` 里**也有一份** `world.data.json`，那才是"这个世界长什么样"（下一步改的是它）。
2. 改 `world.data.json`：名字、品牌文案（锁屏徽标 / 解锁提示）、**App 注册表**（叫什么、什么图标、什么颜色）、
   货币、论坛版块、电台台标、**出厂外观**（`brand.defaultTheme`）、**手机主人的性别/称呼**（`owner.pronoun`，默认「他」）
3. 改 `world.md`（世界设定）、`characters/`（角色）、`system/`（系统 Agent）
4. `data/` 下 **11 个 `.data.json`** 都建好（暂时没有数据的写 `{"xxx": []}` 也行）
5. **设置 → ★ 世界 ★** 里就会出现它

## 五、加一个 App（进阶）

1. 页面放 `phone/engine/apps/<key>/index.html`，头部引这两样：
   ```html
   <link rel="stylesheet" href="../../theme/base.css">
   <script src="../../theme/phone.js"></script>
   ```
2. 在**世界包**的 `world.data.json` → `apps` 里注册：`{ "key", "name", "emoji", "grad", "dock", "route" }`
3. 要存数据就加 `phone/worlds/<世界>/data/<key>.data.json`；想让 Agent 也能读写，就在里面写 `$manifest`
4. 引擎两处各加一行：`phone/engine/index.html` 里的 `frameUrl()` 和 `isAppRoute()`
5. **跑一遍 `phone/_archive/js-check.html`** —— 它自动查语法、单引号、未声明变量、注释吞代码、HTML 结构

## 六、图片和音乐放哪儿

放进 `phone/worlds/<世界>/assets/`。

- 相册 / 电台里点「**从项目里挑**」就能选进来 —— **推荐，网页端也能用**
- 也可以在页面里直接上传：**两端都能传**（2026-10-03 复核；更早的时候网页端曾被拒过 `forbidden`，
  所以万一被拒，界面上会把**原始错误**给你 —— 也可以改用上面的「从项目里挑」）

## 七、改坏了怎么办

最小三步（详细版见 `开发说明.md` 的《调试与自检》）：

1. **先看 console 的第一条红字** —— 它常常不是"症状所在"，而是"整份脚本挂掉所在"
2. 跑 `phone/_archive/js-check.html`
3. **打开对应的 `.data.json`，看实际写进去的是什么** —— 数据就是真相

> 改过引擎文件或数据文件之后，点 **设置 → 系统信息 → 重启手机**（手机只在打开时读一遍数据）。

## 八、几条别踩的

- **`phone/_archive/` 别删** —— 里面是旧版本备份和调试工具
- **数据文件清单只有一处**：`phone.js` 里的 `FILE_NAMES`（加了新数据文件就改那儿）
- **颜色归 `themes.css`，形状（圆角 / 字体）归 `skins.css`** —— App 里别写死颜色，用变量
- **改完在 `CHANGELOG.md` 记一条**：改了什么、为什么
